# APEX Template Reskinning Skill (v5)

Apply APEX 2024/2026 identity to a **finished** deck. Works for **any** source deck—always start from the given source; never copy another deck as the deliverable.

**交稿标准 = 像一套人工排好的 APEX 内容页，不是脚本跑通。**  
脚本只做主题/封面/字体底座。Agent 必须继续改挂、表格换肤、密页重建、全页目视。

## Do not ship

| 不合格做法 | 为什么 |
|------------|--------|
| 只往残留版式灌底图 + logo，不改挂、不重排 | 仍是原稿页，只多了 APEX 标 |
| 改挂到 `Content page` 后，在**旧坐标**上贴纸块、缩字号 | 仍是原稿拼贴，不是 APEX 网格 |
| 残留页改挂后还像「原稿 + logo」 | 未完成；禁止用改挂计数、脚本进度条、或「已加色块」当完成 |

## Master Notes

英文全篇 Latin = **`Avenir Next LT Pro`**。中文稿用微软雅黑。混排：CJK 雅黑，Latin Avenir。

| 元素 | 规则 |
|------|------|
| 封面 | **40pt** 粗斜体 `#991BC5`，浅色左区垂直居中（约 y=2.1"）。交稿前必须审计到 40pt run |
| 页标题 | **28–36pt** 粗 `#991BC5`，按长度灵活，**禁止锁死 28**。节标题 `01`+名 36。长标题先 28，仍溢出才 24 |
| 正文 | **`#310086`**。内容页不用 `#333333` |
| 柱状图 | 紫+青：`#8A2BE2` / `#00E5FF` / `#310086` |
| 参考文献/缩略语 | **9pt `#808080`**，太多则 **8pt** 同色 |

封面副标题在浅色左区可用 `#333333`。脚注不用标题紫。`#991BC5` 只给页标题和节标题 `01`+名。

## When to Use

用户给已排好的 `.pptx`，要「换 APEX 模板」。混搭稿（半 Office / 半 APEX）必须整份做。

不要用来从零做新稿，或美化没有可用版式的烂稿。本技能**不翻译**，措辞跟源稿。

## Golden Rule

不删页、不删句、不删图。品牌、版式归属、表格皮、密页网格都要动。

**做：** 主题；残留版式改挂到 `Content page` / Divider / Title Slide；母版装饰；字体；图表色；页标题 28–36 `#991BC5`；正文 `#310086`；文献 9/8 灰；表格换肤；Office 色含 `a:tc`；封面 40pt 居中；密页**整页重建**；清除批注。

**不做：** 改措辞或造句；删 picture 部件（墙纸可移出画布）；语义对比色（主观/客观粉青、对/错）；把能用的 `空白` 流程图拆掉；在内容页再贴一个 APEX logo；把别的 PPT 整份拷来当交稿。

## 残留版式改挂

不是 APEX 的名字：`标题幻灯片`、`1_标题和内容`、`标题和内容`、`1_节标题`、`节标题`、`空白`、空名称。

| 残留 | 改挂到 | 例外 |
|------|--------|------|
| `1_标题和内容` / `标题和内容` | `Content page` | — |
| `1_节标题` + 实拍/红三角「01」 | 干净的 Content 节标题（`01`+名，均 `#991BC5` 36pt）或 `Divider Slide_Option *` | 校园/医院照和暗红三角不是内容 |
| `空白` + GROUP/SmartArt/自绘流水线 | 可留 `空白`，补 APEX 角标 | 不拆图示 |
| 普通 `空白` / 空名称 | `Content page` | — |

只灌底图、或改挂后不重建，都不合格。

## 页标题

同时满足才是页标题：TITLE / CENTER_TITLE 或名字以 `标题` 开头 / 含 `这里是标题`；y < 1.1"；不是卡片、编号、表头、图注。

显式设 `#991BC5` + 粗 + **28–36pt**。非占位符不会继承 master `titleStyle`。

不要刷标题紫：卡片字、图注、`transformer`、正文强调。页内步号 `1/2/3` 用 `#9B7BF5` ≤24pt。封面由 `rebuild_cover()` 处理。

## 表格

必须扫 `a:tc`。单元格文字不动。

| 部位 | 规格 |
|------|------|
| 表头底 | `accent2` / `#5736CE` |
| 表头字 | `#FFFFFF` 粗 12–13pt |
| 斑马 | `#F7F3FC` / `#E8E2EF` |
| 表正文 | `#5E526E` |
| 线 | 浅紫灰，不要 Office 蓝 |

## 语义色

主观/客观（`#FA0C73` / `#008C95`）、对/错、成对状态色，不要收进 Office remap。

## 密页过关表

改挂之后，下列任一仍成立就必须**整页重建**（新网格 + 把每条字、每张图放进去）。禁止在旧 xy 上贴纸。规则对**任意稿**通用，用当前页现象判断，不要绑死页码。

| 仍成立 = 失败 | 应做成 |
|---------------|--------|
| 字压在主图上 | 标签在图上方通栏，定义在图下 |
| 卡片后面还有装饰/医院墙纸 | 墙纸移出画布；浅卡白底 |
| 断词、典故叠字 | 一行读完或拆成独立框 |
| 截图盖住最后一条 bullet | 截图在栏下方 |
| 因果链挤成一行 | 多行：图 → 步骤 → 证据 |
| 流水线缺关键角色标签 | 可留 `空白`，补标签，不拆图 |
| 形状数仍约等于原稿 Office 页且仍像拼贴 | 按内容重建分区网格 |

重建：先清单全部字和图 → 标题带 / 分区 / 资产新网格 → 断词合并、色块是新结构不是贴纸 → 不造句。

**节标题：** 去掉实拍和红三角；紫字 `01` + 标题 36pt。  
**左编号 + 中图 + 右表：** 编号色块 + 中图不压字 + 右表换肤。  
**主客对照：** 2×2 标签 + 浅柠 `#F8FFE2` / 浅紫 `#E8E5F7`；层级各一行。  
已在 APEX `Content page` 且过关的页：不要为了动而动。

## 封面

每个母版找 `Title Slide` 或 `标题幻灯片`。水晶底 + APEX / APEX China / CAHST / Bayer，分隔线 `#C7C9CB`。只清装饰、留文字框。标题 40pt 粗斜体紫，y≈2.1"。副标题 18pt `#333333`。封面装饰不得进内容页共用版式。

## 内容底

内容页 PNG（约 638KB）已含右下 APEX 标，不要再贴 42KB logo。对每个**已用**且没有全幅底图的内容版式注入。然后改挂残留页。后半本已是 APEX 不能整份跳过。

## 批注与备注

交稿前删除幻灯片**批注**（comments）。演讲者备注若源稿有则保留；不要从其他稿带入批注。

## Script

```bash
python scripts/reskin-apex-v2.py source.pptx
python scripts/reskin-apex-v2.py source.pptx output.pptx
python scripts/reskin-apex-v2.py source.pptx output.pptx --template /path/to/apex-template.pptx
```

`reskin-apex-v2.py` 只做主题 / 封面底座 / 注入 / 字体 / 图表 / 形状层变色。**跑完脚本 ≠ 可交。**  
Agent 必须继续：改挂、表格、`#991BC5` 纪律、正文/文献色、密页按过关表重建、清批注、全页目视。

默认模板：技能根目录 `1 APEX模板和参考页 1 (1).pptx`。OneDrive 打开时先拷本地。

## Agent 流程（任意稿）

1. 源稿拷出 OneDrive。不覆盖源稿。输出默认 `源文件名_APEX.pptx`。
2. 跑 `reskin-apex-v2.py`（底座）。
3. 列每页版式。残留名改挂。扫 `a:tc` 换表肤。
4. 按过关表重建仍像原稿拼贴的密页。禁止贴纸；不抄其他稿的句子。
5. 清除批注。审计封面 40pt、正文 `#310086`、文献 9/8 灰、无 Office 红蓝。
6. 全页导出目视。字压图 / 墙纸 / 断词 / 仍像原稿+logo → 该页重做后再交。

## 交稿清单（全过才能交）

- [ ] 页数 = 源稿；源稿未改
- [ ] 未删句；未删 picture（墙纸可在画布外）
- [ ] 不是「只灌底图」；不是「改挂后旧坐标贴纸」
- [ ] 节标题无实拍/红三角
- [ ] 无双 logo；英文全 Avenir
- [ ] 封面 **审计到 40pt**；页标题 28–36 `#991BC5`
- [ ] 正文 `#310086`；文献 9/8 `#808080`
- [ ] 表格紫头 + 浅紫斑马
- [ ] 密页过关（不压图、无装饰墙纸、无断词、截图不压 bullet、因果链分行）
- [ ] 无批注
- [ ] 语义粉青未抹平；图表紫青

## 教训（短）

1. 混搭稿后半本已是 APEX ≠ 整份完成。  
2. `标题 1` 必须显式上色，占位符清色无效。  
3. 封面搜每个母版的 Title Slide / 标题幻灯片；浅色左区副标题用深色。  
4. 内容 PNG 已含标。讨论/Divider 深紫是对的。  
5. 只灌底或旧坐标贴纸，都不如按过关表重建。  
6. 母版备注压过旧的 28pt 锁和正文 `#333333`。  
7. 每套源稿独立换肤；不要拿别的 PPT 当交稿底。

## 不可破

1. 不增删页、不改措辞、不造句  
2. 不删图；密页可移位/缩放；墙纸可移出画布  
3. 不覆盖源稿  
4. 不把「脚本成功」或「只灌了底图」当完成  
5. 不在内容页再贴 APEX logo  
6. 全稿目视，含前半本  
7. 交稿无批注
